# Create a Function
An individual needs to go grocery shopping and get enough food to make their meals for the week. They want to spend as little money as possible while making sure they consume exactly 2000 calories each day. There are five possible grocery items that they like to choose from: pork, white fish, chicken, salmon, and tofu.

The previous lesson had the following Python code:

```
if c == "tofu":  
    print("Tofu is cheap and has good calories.")
		
elif c == "pork":  
    print("Pork has the most calories.")
		
elif c == "salmon" or c == "white fish":  
    print("Seafood is expensive but is healthy.")
		
else:  
    print("Chicken has fewer calories than pork.")
```

For this assignment, define a function which includes all the `if` statements provided, then call that function with the string "pork" as the argument to print information about that grocery item.
